# Laboratorio Introductorio de PHP

Este repositorio contiene los ejercicios realizados durante el laboratorio introductorio de **PHP**.

Aquí se practican conceptos básicos del lenguaje, como el uso de variables, operaciones matemáticas, formularios y algunos ejercicios sencillos para empezar con PHP.

## ¿Qué hay en el repositorio?

Algunos de los ejercicios realizados son:

* Hola mundo en PHP.
* Uso de variables.
* Operaciones matemáticas.
* Una calculadora sencilla.
* Conversión de pulgadas a centímetros.
* Cálculo del área y perímetro de un círculo.
* Formularios en HTML y PHP.
* Procesamiento de datos enviados mediante formularios.
* Ejemplos de PHP junto con HTML.

## ¿Qué se utilizó?

* PHP
* HTML
* WAMP
* Visual Studio Code
